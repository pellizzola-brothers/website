Tecnologias por Componente
🕹️ Jogo — Pellizzola Brothers
C Linguagem principal, filosofia suckless
raylib Renderização gráfica e câmera com suavização
jansson Leitura e parsing de LEVEL_DATA.json
FluidSynth Síntese MIDI em tempo real via SoundFont
libzip Leitura do formato .lvl (ZIP com JSON e MIDI)
⚙️ Editor de Levels
Electron Aplicação desktop cross-platform
JavaScript Lógica da interface e do editor
Canvas API Grade 30×20, pintura e pré-visualização de cenas
BLOCK_REGISTRY Registro centralizado de blocos com tags e categorias
🌐 Plataforma Web
HTML / CSS / JS Frontend com i18n PT/EN integrado
Backend Node.js API REST, upload .lvl, autenticação JWT
bcrypt Hash seguro de senhas
Railway Infraestrutura e hospedagem em produção
🗄️ Banco de Dados
PostgreSQL SGBD relacional, schema com 5 tabelas
Neon PostgreSQL serverless em nuvem
SERIAL / FK Cascade Integridade referencial e exclusão em cascata
Índices compostos Otimização de filtragem e ordenação por relevância
🎨 Arte & Identidade Visual
Aseprite Editor principal de pixel art
NES Palette 54 cores únicas do processador gráfico do NES
Sprites 32×32 px 29 elementos: blocos, personagens e decorações
Spritesheet de corrida Animação completa dos personagens jogáveis
📦 Formato de Intercâmbio — .lvl
ZIP Contêiner único com todos os recursos do level
LEVEL_DATA.json Metadados e grade de 30×20 por cena (600 células)
MIDI_DATA/ Até 10 arquivos .mid de trilha sonora
Multi-cena Até 9 cenas independentes por level

🌐

🗄️
